## 1. 데미지 계산 엔진 (핵심)

### 1.1 구조

모든 항목은 **곱연산**. 인게임 정보창의 % 수치를 그대로 입력값으로 사용한다.

```js
// 모든 인자는 정보창 표시값(%) 그대로. mode = { boss: bool, skill: bool }
function realDamage(s, mode) {
  const atk     = s.atkFlat * (1 + s.atkPct / 100);              // 합산 공격력
  const crit    = 1 + (s.critRate / 100) * (s.critDmg / 100);    // 평균 크리 배율
  const target  = mode.boss  ? (1 + s.bossDmg   / 100) : (1 + s.normalDmg / 100);
  const atype   = mode.skill ? (1 + s.skillDmg  / 100) : (1 + s.basicDmg  / 100);
  const dmgRange= ((s.minMult + s.maxMult) / 2) / 100;           // 최소~최대 평균 배율
  const skillLv = 1 + s.skillLevel * (s.perLevel / 100);         // ⚠ perLevel 미정(보정 필요)

  return atk
    * (1 + s.dmg       / 100)   // 데미지
    * (1 + s.amp       / 100)   // 데미지 증폭
    * (1 + s.statRatio / 100)   // 스탯 비례 데미지
    * crit                      // 크리티컬
    * target                    // 보스/일반 몬스터 데미지
    * atype                     // 스킬/기본 공격 데미지
    * (1 + s.finalDmg  / 100)   // 최종 데미지
    * dmgRange                  // 최소~최대 데미지 배율(평균)
    * skillLv;                  // 스킬 레벨
}

// 비교: realDamage(변경안) / realDamage(현재) - 1 = 실데미지 변화율
```

### 1.2 검증된 관계

- `합산 공격력 = 고정공격력 × (1 + 공격력%)` → `73,848 × 54.971 = 4,059,498` (인게임 합산과 일치 ✓)
- 스킬 공격력%는 합산에 다시 곱해져 최종 공격력이 됨 (`4,059,498 × ≈1.407 = 5,711,714`).

### 1.3 주의

- **전투력은 이 식과 별개**로 게임이 매기며, HP·방어·회피 같은 생존 스탯까지 포함해 부풀려짐 → **신뢰 금지**. 비교는 항상 실데미지로.
- 이 모델은 **상대 비교는 정확**. 절대값을 인게임과 100% 일치시키려면 §5 보정 필요.

## 3. 스탯 분류 (딜 / 뻥 / 상황부)

- **딜 (실데미지 O)**: 공격력(+/%), 데미지%, 데미지 증폭, 스탯 비례, 크리율, 크리뎀, 보스뎀, 일반뎀, 기본공격뎀, 스킬뎀, 최종뎀, 최소/최대 데미지 배율, 방어 관통력, 상태이상 데미지, 스킬 레벨.
- **뻥/생존 (실데미지 X, 전투력만 ↑)**: 최대 HP, 방어력, 받는 피해 감소, 회피, MP·MP회복, 디버프 저항·내성, 크리티컬 저항, 버프 지속시간, 경험치·메소 획득량.
- **상황부**: 명중(상대 회피 있을 때만), 스킬 쿨감(시간당 딜↑, 한 방은 그대로), 디버프 적중(디버프 딜러 한정).

## 4. 시스템 → 스탯 매핑

모든 성장 시스템은 **새 곱연산 층이 아니라 위 스탯 버킷으로 흘러들어감.**

| 시스템 | 주는 스탯 |
|---|---|
| 동료 (노멀·레어) | 공격력(+) |
| 동료 (영웅+) | 최소/최대 데미지 배율, 명중, 일반몹뎀 등 (동료마다 다름) |
| 동료 (메인) | 본체 공격력의 일정 % 계승 (동료 레벨↑ → 비율↑) |
| 동료 보유효과 | 예: 히어로=최대 데미지 배율, 섀도어=최소 데미지 배율 |
| 용사의 힘 | 공격력·방어력 등 추가 능력치, 단계별 슬롯 개방 (용사의 증표 소모) |
| 스타포스 | 부위별 기본 옵션 증폭. 11성↑ 확률 1/3, 13→14 하락, 20→21 파괴 |
| 잠재(큐브) | 장갑=크리뎀, 견장=방관, 반지/목걸이=모든 스킬 레벨, 벨트=버프 지속, 신발=동료 소환 지속 (에픽 이상) |
| 주문서 강화 | 기본 옵션 상승 |

## 5. 미해결 / 보정 필요 항목

1. **스킬 레벨 효과(레벨당 %)** — 게임 내부 계수라 미상. 인게임에서 옵션 하나 바꿔 전투력/데미지 변화를 본 뒤 역산해 보정. (현재 프로토타입엔 `perLevel=0`)
2. **크리 기본 배율 모델** — `1 + 크리율×크리뎀`로 근사. 실제 크리 배율 정의(기본배율 포함 여부) 검증 필요.
3. **방어 관통력** — 적 방어력에 의존. 정확 계산하려면 "적 방어력" 입력값이 필요. 현재 엔진 미반영.
4. **게임 화면 가로/세로** — UI 재구성 방향 결정에 필요. 미확인.
5. **시스템 단계별 정확 수치** — 스타포스 N성당 증가량, 잠재 등급별 옵션 풀, 동료 레벨별 효과, 용사의 힘 단계별 수치. (운영 도구로 띄울 때 점진 수집)
