## 1. 한 줄 요약

메이플 키우기 유저가 **게임과 닮은 친숙한 UI**에 자기 스탯을 입력하고, "이 장비·업글이 실제로 내 딜을 올리는가"를 **전투력(뻥투력)이 아닌 실데미지**로 비교하는 도구.

- 메키픽 / 메키펀 **상위호환**.
- 목표: 포트폴리오 + 도메인 운영 + 광고 수익.

### 역할 분담

| 역할 | 담당 |
|------|------|
| **비오** | 기획 · 디자인 · 프론트엔드 (피그마 / 클로드 디자인) |
| **Claude** | 계산 엔진 · 공식 검증 · 로직 |

## 2. 핵심 제품 결정 (확정)

1. **"현재/목표 두 칸" 모델 폐기.** 현재 스탯 1회 입력 + "바꿀 것만(델타)" 입력 → 결과. 목표 수치 칸 없음.
2. **게임과 닮은 친숙한 입력 UI.** 게임의 정보구조·배치만 참고, 넥슨 에셋·그래픽 복제 금지, 시각 디자인 100% 자체 제작.
3. **레이아웃: 세로 9:16, 모바일 우선 반응형(1280 내).** 게임이 가로면 1:1 복제 대신 친숙 요소를 세로 재배치.
   - ⚠ 게임 화면 가로/세로 = **미확인, 확인 필요**.
4. **실데미지와 전투력을 분리 표시** → 뻥투력 즉시 식별.
5. **딜 스탯 / 생존·유틸 스탯 구분 표시.**
6. **스크린샷 OCR 자동입력은 후순위 실험** (캡처 편차·이펙트 겹침으로 오류 불가피).
7. **상세 스탯 데이터 소스 = 본인 정보창 입력**이 유일·최선.
   - 메이플 키우기 공식 오픈 API 없음. 랭킹 엔드포인트는 전투력·직업·레벨만 제공 → 상세 스탯 자동연동 불가.
