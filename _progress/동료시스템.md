# 동료 시스템 — 구조 + 실데미지 티어 (2026-06-08)

> 출처: 나무위키(시스템 설명·장착효과 매핑). 수치(계승비율·장착효과 %)는 [미측정] → 부캐 수집 대상.
> 본캐 직업 = 캡틴(주스탯 DEX).

---

## 1. 구조

### 메인 동료 (소환형)
- 강력한 쿨타임 기술. **30초 소환** 전투, 프리셋으로 자동/수동 선택. 장착효과도 적용.
- **소환 당시 유저 스펙 계승** → 소환 직전 버프 다 켠 상태가 DPS 최대.
- 공격력 = **캐릭터 공격력의 일정 비율 계승**. 비율은 **동료 레벨↑ 시 상승**(같은 동료 소모해 레벨업).
- ⚠ 비율 계승이라 **부캐 절대값을 본캐에 직접 못 씀 → 비율(%)로 기록**해야 본캐 적용 가능.

### 서브 동료
- 소환 안 됨, **장착효과만** 부여. 동료 소환 레벨↑ → 최대 서브 슬롯 수 증가, **8레벨에 전 슬롯 오픈**.

### 등급
- **에픽 이상**: 장착효과 + 특수효과 → 용도별 프리셋. 성능 티어 갈리나 보유효과 때문에 **전부 획득** 권장.
- **레전드리**: 레벨 높을수록 **4차 스킬 해금** → 급격히 강해짐.

**엔진 외 (별도 축):**
- **보우마스터(공격속도)** — 1타 데미지 0, **사냥속도(DPS)·원킬구간 핵심**. Phase1 사냥속도 모델 대상.
- **다크나이트(명중)** — 명중 충분하면 실뎀 0(뻥). 상대 회피 높을 때만.
- **신궁(상태이상 데미지)** — 캡틴은 상태이상 딜러 아님 + 엔진 미반영 → 본캐 무관.

| 동료 | 효과(4차) | 일반몹 | 보스 |
|------|------|---:|---:|
| 썬콜 | 일반몹뎀+20% | **+13.3%** | — |
| 나이트로드 | 보스뎀+20% | — | **+14.8%** |
| 바이퍼 | 주스탯+12% | +8.0% | +8.0% |
| 불독 | 크확+12% | +7.3% | +7.3% |
| 히어로/섀도어 | 데미지배율+20% | +6.5% | +6.5% |
| 비숍 | 스킬뎀+8% | +6.4%(스킬) | +6.4%(스킬) |

- **+ 보유효과(전동료 공통, 4차)**: 데미지+10% → **+2.86%** (누구를 키워도 동일하게 추가).
- 💡 **전용옵션이 압도적**(썬콜=사냥, 나이트로드=보스 — 수치 20%). **바이퍼(주스탯)가 범용 2위**(공격력+스탯비례 이중경로). **캡틴(크뎀)은 의외로 최하** — 본캐가 이미 크뎀 101%로 높아 한계효율 낮음(곱셈 함정).
- ⚠ 위는 "서브 슬롯 우선순위"용. 메인 소환딜(계승)·등급 보유효과·레전드리 4차스킬 때문에 **결국 전부 수집**이 정답.

## 4. 차수 구조 (실측 확보 — 상세 수치 `동료-데이터.md`)
스크린샷 52장 판독으로 확정(정답지 3장 일치):
- **장착효과 직업별 분기 = 2차부터** (지망생·1차는 전직업 공통 = 공격력). ※ 기존 "3차부터" 가설 **정정**.
- **계승비율(Lv.1, 전직업 공통)**: 1차 50% · 2차 50% · 3차 25% · 4차 18% (차수↑일수록 Lv.1 계승 **낮음** — 특이. 레벨업 시 변화는 미측정).
- **장착효과 수치**: 2→3→4차 = **×2씩(2→4차 ×4)** 전직업 일정. 예: 캡틴 크뎀 3%→6%→12%.
- **보유효과(차수별 전직업 공통)**: 1차 공격력50·HP500 / 2차 주스탯70·HP1,750 / 3차 데미지5%·HP10% / 4차 데미지10%·HP15%.
- 12직업 1~4차 전부 확보 완료(다크나이트 2차=명중6 포함).

## 5. 미측정 (부캐 수집 대상)
| 항목 | 상태 | 수집법 |
|------|------|------|
| 계승비율 **레벨업 시 변화** | 🔴 | 같은 동료 Lv.1→2→… 계승비율% 표기 |
| 장착효과 **레벨당 증가량** | 🔴 | 서브 동료 Lv업 전후 캐릭터창 차이 (지망생 Lv1→2 공격력60→66 참고) |
| 서브 슬롯 오픈 레벨 | 🟡 | 나무위키=8레벨 전개방. 실측 확인 |
| 에픽+ 특수효과 / 레전 4차스킬 | 🔴 | 에픽 이상 확보 시 |
