## 1. 구조

### 동료 효과 3종 (게임 내 공식 설명 확정)
1. **보유 효과** — 동료를 보유(획득)하는 것만으로 적용.
2. **장착 효과** — 메인 또는 서브 슬롯에 장착 시 적용.
3. **메인 스킬 효과** — 메인 슬롯 장착 + 소환 시 스킬 발동으로 적용.

> 스킬 목록에서 opacity 낮은 스킬 = 동료 레벨 미달로 아직 미해금.

### 차수 구조 및 레벨업 메커니즘 (2026-06-09 확정)
- **차수(1차/2차/3차/4차)는 승급 단계가 아니라 별개 카드(독립 동료)다.** 예) "나이트로드 1차"와 "나이트로드 2차"는 별개의 동료로 각각 따로 가챠로 뽑고 따로 카드로 레벨업한다. 1차를 키워서 2차가 되는 진화·승급 시스템이 아님.
- **차수 = 동료의 티어(등급).** 높을수록 강하지만 가챠 획득 확률이 낮다. 1~4차 동료는 동시에 병렬로 공존하며 각자 별도로 운용된다.
- **레벨업 = 중복 카드 소모 시스템.** 가챠에서 중복 획득한 동료 카드를 소모해 레벨업.
- 그리드 칸의 "X/Y" 숫자 = [현재 보유 카드 수 / 다음 레벨 도달 필요 카드 수]. 예: 전사지망생 Lv.37, "88/113" = 현재 88장 보유, Lv.38 도달에 113장 필요.
- **차수별 고유 최대레벨 상한 (확정):** 1차=50, 2차=30, 3차=10, 4차=[미확인].
  - 게임 상세창 "Lv.13/50"에서 분자=현재레벨, 분모=해당 차수 동료의 최대레벨 상한.
- **하위 차수가 고레벨인 이유:** 가챠 확률 높아 카드 다량 확보 → 자연스럽게 고레벨. 4차는 확률 낮아 카드 부족 → 저레벨에 머묾. (본캐 4차 동료가 저레벨인 구조적 이유.)
- **계산기 설계 시사점:** 동료 레벨은 가챠 운에 좌우되어 자동 산출 불가 → 소환딜 모델링 시 유저가 자기 동료의 차수+레벨을 직접 입력해야 함.

### 메인 동료 (소환형)
- 강력한 쿨타임 기술. **30초 소환** 전투, 프리셋으로 자동/수동 선택. 장착효과도 적용.
- **소환 당시 유저 스펙 계승** → 소환 직전 버프 다 켠 상태가 DPS 최대.
- 공격력 = **캐릭터 공격력의 일정 비율 계승**. 비율은 **동료 레벨↑ 시 상승**(같은 동료 소모해 레벨업).
- 메인 슬롯 장착 = 일정 시간마다 소환 + 보유 스킬 발동.
- ⚠ 비율 계승이라 **부캐 절대값을 본캐에 직접 못 씀 → 비율(%)로 기록**해야 본캐 적용 가능.

### 서브 동료
- 소환 안 됨, **장착효과만** 부여(스킬 미발동). 동료 소환 레벨↑ → 최대 서브 슬롯 수 증가, **8레벨에 전 슬롯 오픈** [나무위키, 실측 미확인].

### 등급
- **에픽 이상**: 장착효과 + 특수효과 → 용도별 프리셋. 성능 티어 갈리나 보유효과 때문에 **전부 획득** 권장.
- **레전드리**: 레벨 높을수록 **4차 스킬 해금** → 급격히 강해짐.

## 1-1. 공격력 계승비율 공식 (게임 내 설명문 확정 — 2026-06-09)

**게임 공식 원문:**
> "소환된 메인 동료는 내 캐릭터 공격력의 일정 비율만큼 공격력이 적용됩니다. 공격력 계승 비율은 동료의 레벨에 따라 상승하며, 플레이어의 레벨이 메인 동료의 직업 차수에 해당하는 전직 레벨보다 낮다면 그 차이에 비례하여 감소합니다."

**확정된 전직 요구 레벨:**
| 차수 | 전직 요구 레벨 |
|:---:|:------------:|
| 2차 | Lv. 30 |
| 3차 | Lv. 60 |
| 4차 | Lv. 100 |

**확정된 플레이어 레벨:**
- 본캐: **레벨 84** (3차 요구Lv.60 충족 → 3차 페널티 0. 4차 요구Lv.100 미달 → 4차 페널티 있음)
- 부캐: **레벨 36** (2차 요구Lv.30 충족. 3차 요구Lv.60 미달 → 페널티 있음)

**공식 구조:**

계승비율 = base곡선(동료레벨) × min(1, 플레이어레벨 / 전직요구레벨)

- base곡선: 동료 레벨 상승 시 선형 증가. **3차 ✅ 확정: 45+5×동료레벨** (+5%p/레벨, Lv.1=50%).
- 1·2차 기울기: [가설] +1%p/레벨, base 불명.
- 페널티계수: 플레이어레벨 ≥ 전직요구레벨이면 1.0. 미달 시 min(1, 플레이어레벨/요구레벨).
- 1차: 전직 요구 없음 → 페널티 없음.
- 정성(차이 비례 감소): 게임설명 ✅. 정량(min(1,레벨/요구)): 🟡 [가설 유력].

**페널티 공식 검증 데이터:**

| 케이스 | 플레이어레벨 | 동료레벨 | base(추정) | 페널티계수 | 예측 | 실측 | 일치 |
|--------|:----------:|:-------:|:----------:|:--------:|:----:|:----:|:----:|
| 부캐 4차 | 36 | [불명] Lv.1 추정 | 50% | 36/100=0.36 | **18%** | 18% | ✓ |
| 본캐 4차 | 84 | [불명] Lv.3 추정 | 60% | 84/100=0.84 | **50.4%** | 50.4% | ✓ |
| 부캐 3차 | 36 | Lv.1 | 50% | 36/60=0.6 | **30%** | 25% | ✗ outlier |

> 부캐 3차 25%는 공식 예측 30%와 불일치. 4차·본캐가 전부 정확히 맞으므로 **haiku 판독 노이즈 가능성이 높음**. 본캐 4차 동료 레벨 확인되면 ✅ 전환 가능.

**본캐 실측 데이터 요약 (2026-06-09 갱신):**

| 차수 | 동료 레벨 | 계승비율 | 페널티 여부 |
|:---:|:--------:|:-------:|:----------:|
| 1차 | 13/50 | 66% | 없음 |
| 1차 | 14/50 | 67% | 없음 |
| 2차 | 6/30 | 66% | 없음 (레벨84≥30) |
| 2차 | 7/30 | 67% | 없음 |
| 2차 | 8/30 | 68% | 없음 |
| 3차 | 1/10 | 50% | 없음 (레벨84≥60) ✅ base |
| 3차 | 2/10 | 55% | 없음 ✅ |
| 3차 | 3/10 | 60% | 없음 ✅ |

**3차 곡선 ✅ 확정:** 45+5×동료레벨. Lv.1=50%·Lv.2=55%·Lv.3=60% — 3점 완벽 선형.

## 4. 차수 구조 (실측 확보 — 상세 수치 `동료-데이터.md`)
스크린샷 52장 판독으로 확정(정답지 3장 일치):
- **장착효과 직업별 분기 = 2차부터** (지망생·1차는 전직업 공통 = 공격력). ※ 기존 "3차부터" 가설 **정정**.
- **계승비율**: 동료레벨 상승 + 플레이어레벨 페널티계수의 함수 (1-1절 참조). 구 기록 "3차=25%, 4차=18%"는 부캐 저레벨 페널티 상태값으로 정정됨. 본캐 기준 3차 Lv.1 = 50%.
- **장착효과 수치**: 2→3→4차 = **×2씩(2→4차 ×4)** 전직업 일정. 예: 캡틴 크뎀 3%→6%→12%.
- **보유효과(차수별 전직업 공통)**: 1차 공격력50·HP500 / 2차 주스탯70·HP1,750 / 3차 데미지5%·HP10% / 4차 데미지10%·HP15%.
- 12직업 1~4차 전부 확보 완료(다크나이트 2차=명중6 포함).
